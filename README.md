# 訓練記錄

健身房用的手機網頁 App：看上次的重量、次數、RIR（保留次數），每做完一組就直接寫進自己的 Google 試算表。

- **前端**：本資料夾的靜態網頁，放在 GitHub Pages 上
- **後端**：綁在試算表上的 Google Apps Script 程式（`Code.gs`），用權杖驗證每一次連線
- **隱私**：程式碼裡沒有任何網址或權杖；連線設定只存在你的手機上

---

## 安裝教學

整個安裝分三部分，大約 10 分鐘：

1. 準備試算表與後端程式（電腦上做）
2. 把 App 加到 iPhone 主畫面
3. 把手機 App 連上試算表

### 一、準備試算表與後端程式（用電腦）

1. 準備好「訓練追蹤」Google 試算表（自己的檔案，或從範本建立副本）。
2. 在試算表上方選單點 **擴充功能 → Apps Script**。
3. 確認編輯器裡有 `Code.gs` 的程式碼；如果是空的，把 `Code.gs` 的內容整份貼上，按 **儲存**（磁碟片圖示）。
4. 設定權杖（一組只有你知道的密碼）：
   - 左側點 **⚙️ 專案設定** → 捲到最下面 **指令碼屬性** → **新增指令碼屬性**
   - 屬性填 `TOKEN`，值填一串夠長、不好猜的英數字（例如 20 個字以上）
   - 按 **儲存指令碼屬性**
5. 部署成網頁應用程式：
   - 右上角點 **部署 → 新增部署作業**
   - 類型（齒輪圖示）選 **網頁應用程式**
   - **執行身分**：我
   - **具有存取權的使用者**：任何人
   - 按 **部署**；第一次會要求授權，選自己的 Google 帳號 → 允許
6. 取得連線碼：
   - 回到編輯器，上方函式下拉選單選 **showSetupCode** → 按 **執行**
   - 在下方 **執行記錄** 會看到一整行「網址|權杖」，整行複製起來（可以先傳到手機，例如用 LINE 傳給自己或存到備忘錄）

> ⚠️ 這一行等於你試算表的鑰匙，不要貼到公開的地方。

### 二、把 App 加到 iPhone 主畫面

1. 用 iPhone 的 **Safari** 打開：`https://spv7d5ymkg-beep.github.io/gymlog/`
2. 點下方的 **分享** 按鈕（方框加向上箭頭）
3. 往下滑，點 **加入主畫面** → **新增**
4. 之後**一律從主畫面的「訓練記錄」圖示開啟**，不要在 Safari 分頁裡用（在 Safari 分頁裡，資料可能被系統清掉）

### 三、連上試算表

1. 從主畫面打開 App，會看到「連線設定」畫面
2. 把第一部分第 6 步複製的那一整行「網址|權杖」貼進去
3. 按 **儲存並測試**；成功就會進到首頁

完成！建議先在首頁輸入一筆體重，自重型動作的訓練量會用到它。

## 日常使用

1. 首頁選今天的訓練日（或點「繼續今天的訓練」）
2. 數字已經依上次紀錄預填好，確認或調整後按 **完成第 N 組**
3. 沒有網路也能照常記錄；App 會先存在手機裡，有網路時自動補送

## 常見問題

**連線失敗怎麼辦？**
- 確認貼上的是 **完整的一整行**，中間有 `|`
- 確認部署時「具有存取權的使用者」選的是 **任何人**
- 確認指令碼屬性的 `TOKEN` 有儲存

**後端程式改了之後要怎麼更新？**
- 到 Apps Script 點 **部署 → 管理部署作業 → ✏️ 編輯 → 版本：建立新版本 → 部署**，網址不會變
- 不要按「新增部署作業」，那會產生新的網址；如果不小心按了，到 App 的 **設定 → 重新設定連線**，貼上新的連線碼即可

**前端更新了，手機還是舊版？**
- 從多工畫面把 App 完全滑掉再重開；還是舊版就再重開一次

**換手機或想換權杖？**
- 到 App 的 **設定 → 重新設定連線**，重新貼上連線碼

## 開發者備註

- 修改 `index.html` 時，請一併把 `sw.js` 裡的 `VERSION` 加一，讓手機上的舊快取被清除
- 前端沒有框架、不需要建置；合併進 `main` 後 GitHub Pages 會自動更新
